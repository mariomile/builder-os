# Two-proportion calculations

Load only for binary A/B sample size or analysis. This skill-local reference and `../scripts/proportions.mjs` resolve relative to their real source paths. No connected provider or script execution is required for design; no baseline may be invented.

## Calculation source and assumptions

The executable source is `scripts/proportions.mjs` in the owning skill directory, using only Node built-ins. Equal allocation, independent binary outcomes, one primary metric, fixed horizon, two-sided alpha 0.05 and power 0.80. It uses approximate normal quantiles 1.96 and 0.84, with ceiling to a whole count per arm:

```
p2 = p1 + absolute_MDE             (increase)
p2 = p1 - absolute_MDE             (decrease)
absolute_MDE = p1 × relative_MDE   (when supplied as relative lift)
n = ceil((1.96 + 0.84)^2 × (p1(1-p1) + p2(1-p2)) / (p2-p1)^2)
```

Inputs are probabilities/fractions (0.05 = 5%); 5pp is 0.05, 10% relative lift is 0.10. Both baseline and alternative must be strictly in (0, 1); the helper rejects impossible effects, zero/negative effects and non-finite values. This simplified planning approximation is not an exact guarantee of power. Check expected successes/failures are sufficiently large; rare outcomes, cluster assignment, repeated measurements, uneven allocation, multiple arms and sequential stopping require their own calculation. Record attrition adjustments separately instead of silently changing n.

From the installation root, run `node skills/experiment-methodology/scripts/proportions.mjs 0.05 0.05 absolute` or `node skills/experiment-methodology/scripts/proportions.mjs 0.05 0.10 relative`. This is an optional local calculation, not a host requirement. The formula is the identical inline fallback.

## Readout

Choose the test before outcomes. For an ordinary independent binary fixed-horizon test, a pooled two-proportion z-test under the zero-difference null uses:

```
p_pool = (success_control + success_treatment) / (n_control + n_treatment)
SE_null = sqrt(p_pool × (1-p_pool) × (1/n_control + 1/n_treatment))
z = (p_treatment - p_control) / SE_null
p_value = 2 × (1 - Phi(abs(z)))
```

An approximate difference interval uses the unpooled standard error:

```
SE_difference = sqrt(p_control(1-p_control)/n_control + p_treatment(1-p_treatment)/n_treatment)
95% CI = difference ± 1.96 × SE_difference
```

These approximations fail at sparse/boundary counts; do not report a zero-width interval after zero conversions as certainty. Use a suitable score/exact method when needed. A pooled test and unpooled Wald interval can disagree near a threshold: state both methods rather than requiring them to match. Account for multiplicity when the registered design has several hypotheses.

| Finding | Interpretation |
|---------|----------------|
| Benefit above business threshold, acceptable guardrails, valid design | Apply the preregistered launch rule; statistical significance alone does not authorize a release |
| Significant improvement smaller than business threshold | Evidence of an effect, not automatically enough business value |
| Meaningful harm or guardrail breach | Apply the registered stop/kill rule |
| Interval spans meaningful benefit and harm/zero | Inconclusive; do not claim no effect |
| Interval excludes effects worth pursuing | Evidence against that size of benefit; practical-equivalence claims need registered margins/method |

Do not extend a completed fixed-horizon test based on nonsignificance. Optional stopping needs a prespecified sequential design/alpha spending; a blinded sample-size reassessment must follow its prespecified rule and cap. Otherwise preregister a new independent follow-up. Report assignment validity, counts, effect in pp and relative percent, interval, test method, guardrails and the result's limits.
